# Photo 101 — A-1 Focus Lab

A Canon A-1 camera simulator: a depth-of-field and exposure playground built around one setup, the **Canon A-1 with the FD 50mm f/1.8** on 35mm film.

- Three scenes (backyard, mixed sun/shade, dim living room) with fixed subjects.
- Turn the aperture ring and focusing ring and see what lands sharp on the negative.
- Viewfinder LED readout, distance map, exposure-triangle demo, and a guide to every control on the camera.

## Run it

Open `index.html` in a browser. It is a single self-contained page with no build step.

Live version: https://claude.ai/artifact/4sR4d8KUCcLJJPQue5txjo
